# Research Index

This directory contains all deep research projects conducted using the Claude Deep Research Agent skill. Each research project is organized in a dated subdirectory following the naming convention: `YYYY-MM_Topic_Name`.

## Organization Strategy

- **Naming Convention**: `YYYY-MM_Topic_Name` for chronological sorting and easy retrieval
- **Background Research**: Prefixed with `00_` to indicate foundational/contextual materials
- **Version Control**: Research outputs are committed to the main branch; skill versions use branches and tags
- **Navigation**: Each research project contains its own README.md for detailed navigation

## Naming Convention Guidelines

When adding new research projects, follow this structure:

```
RESEARCH/
└── YYYY-MM_Topic_Name/
    ├── README.md (master navigation for this project)
    ├── 00_Background_Research_Topic/ (optional background materials)
    ├── 01_Analysis/ (core analysis documents)
    ├── 02_Visualizations/ (charts, graphs, diagrams)
    ├── 03_Deliverables/ (final outputs, presentations)
    └── 04_Appendices/ (methodology, sources, raw data)
```

**Naming Best Practices**:
- Use `YYYY-MM` prefix for chronological sorting (e.g., `2025-01`)
- Use underscores between words for readability (e.g., `Plume_ADGM_Partnership`)
- Keep names concise but descriptive (3-5 words maximum)
- Use title case for topic names (e.g., `Strategic_Partnership` not `strategic_partnership`)
- Prefix background/contextual materials with `00_`
- Number primary sections: `01_`, `02_`, `03_` for logical ordering
